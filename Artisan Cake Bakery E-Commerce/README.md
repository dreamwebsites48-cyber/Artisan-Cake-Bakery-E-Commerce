# Artisan Cake Bakery E-Commerce

A modern, luxury, fully responsive demo e-commerce website for a premium cake bakery.
Built with HTML5, CSS3, JavaScript, Bootstrap 5, PHP, and MySQL.

## Features
- **Frontend**: Glassmorphism UI, smooth animations, premium typography, responsive design
- **Backend (Demo Structure)**: PHP structure with MySQL database schema provided
- **Pages**:
  - Home (Hero, Categories, Featured Products, Special Offers)
  - Shop/Cakes List
  - Product Details
  - Cart
  - Checkout
  - User Login & Registration
  - User Dashboard
  - Admin Login
  - Admin Dashboard

## Tech Stack
- HTML5 / CSS3 / JavaScript
- Bootstrap 5 (CSS framework)
- FontAwesome (Icons)
- Animate.css (Animations)
- PHP / MySQL (Database Schema)

## Setup Instructions
1. Upload the files to your local server (XAMPP/WAMP) or live hosting in the `htdocs` or `public_html` directory.
2. Create a new MySQL database named `artisan_cake_db`.
3. Import the `database/schema.sql` file into your database.
4. Update the database credentials in `includes/db.php`.
5. Access the site via `http://localhost/Artisan%20Cake%20Bakery%20E-Commerce/` (or your chosen directory name).
6. Demo Admin Login: `admin` / `password`
